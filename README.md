# Kompas Nood

Noodpagina voor een kompaswandeling. Je loopt op papier en kompas; deze pagina is alleen voor als je echt de weg kwijt bent.

1. **Welke kant op?** Koers en afstand naar je volgende doel, en hoe ver je naast je koerslijn zit.
2. **Waar ben ik op mijn kaart?** Je positie als RD-coördinaat, om zelf op het kilometerraster van je kaartblad te vinden.
3. **Kaart.** Pas als het echt niet anders kan (heeft internet nodig).

De route komt uit de QR-code op de kompastabel van de wandelplanner. De doelen staan alleen in het deel na `#` van de link en worden nergens opgeslagen. Hint 1 en 2 werken zonder internet zodra de pagina één keer geopend is.
